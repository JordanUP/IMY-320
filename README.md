# How To Use

## Requires the Live Server Extension on VSCode
### Made by Ritwick Dey

--> Open Folder > Full project folder
--> Go Live [on Status Bar] or press F1 > Live Server: Open With Live Server

> Why Live Server?
> Due to browsers not supporting direct file access with normally opened HTML files, the Live Server bypasses those errors and allow for the use of JSON files without complex backend systems
